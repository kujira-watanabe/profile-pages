13行プロンプト実践シート

まず、これだけで始められます。

使い方は3つだけ

  1. 下の3つの空欄を埋める。決まっていないところは、決まっていないまま書く。
  2. そのままAIに貼る。書き方は整えなくていい。
  3. 返事を読んで、違えば「違う」と返す。（返し方は「次の一言カード」）

コピペ用（そのまま貼る）

理想：
現状：
どうする？：
  • 理想　こうなりたい。こうなってほしい。「もう少し〜したい」「〜が減ってほしい」くらいでいい。理由まで書けなくていい。
  • 現状　今、こうなっている。困っていること、やってみたこと、わかっていないこと。「原因はわからない」も現状のうち。
  • どうする？　AIと、まず何をするか。最終的な答えを決める欄ではない。迷ったら「まず整理して」。

決まっていないときの書き方（例）

雑でいい、の見本です。

理想：もう少し仕事を楽にしたい。
現状：最近ずっと忙しい。でも、何が原因なのかはよくわからない。
どうする？：まず整理して。

これだけで、AIは「何が忙しさを作っているか」を聞き返してきます。そこから会話が始まります。

「どうする？」に入れる言葉の例

したいこと書く言葉
頭の中を出したいまず整理して
自分でも説明できない必要なことを質問して
方向を決めたい方向性を一緒に整理して
決めるための材料がほしい判断するためのポイントを整理して
書く前に考えたい相手に何を伝える必要があるか整理して
案がほしい現実的な案を3つ出して
わからないことがある一般的にはどうしているか調べて

貼ったあと

返事が来たら、正しいかどうかより「自分の言いたかったことと合っているか」を見る。

合っていなければ、「そこじゃない」「もう少しこういう感じ」と返す。
AIは怒りません。往復するほど、自分の考えがはっきりしてきます。

2生のやり取り実例集

「なんか違う」と言っていいことがわかります。

企画を考える。判断する。伝える。
この3つの場面で、僕が実際にAIと往復したやり取りを載せています。きれいに整えた例ではなく、実物です。

企画編企画を考えるときの往復 判断編迷って決めるときの往復 伝える編相手に伝える文章を作るときの往復

3次の一言カード

会話が止まったときに、続けられます。

AIの返事を見て、次に何と言えばいいかわからなくなったときの返し方です。そのまま貼れます。丁寧に書かなくていい。

返事がずれているとき

  • それは違う。こういう感じ
  • そこじゃない。聞きたいのは〜のほう
  • 方向は合っているけど、なんとなく弱い。違和感の正体を一緒に整理して
  • 今回の条件だと、それは使えない。条件は〜

もっと深めたいとき

  • もう少し具体的に
  • それはなぜ？
  • 例を3つ出して
  • その中で、今の自分に一番近いのはどれ？

自分が言葉にできないとき

  • 必要なことを質問して
  • まだ自分でもうまく説明できていない。質問しながら一緒に整理して
  • なんで、この理想が欲しいんだっけ？
  • 理想に対して、今、何が足りていないんだっけ？

別の見方がほしいとき

  • 別の視点だと？
  • 顧客から見てどう？
  • 半年後まで考えると？
  • この案に反対する人なら、何を問題にする？
  • この判断が失敗するとしたら、どんな理由がありそう？

決めたいとき

  • 判断するためのポイントを整理して
  • やめた方がいい理由と、やった方がいい理由を両方出して
  • どちらが正しいかではなく、どんな条件ならＡ、どんな条件ならＢか整理して
  • まず1か月だけ試すなら、どう設計すればいい？

調べてほしいとき

  • 普通はどうしている？
  • より良いやり方は？
  • 公式の最新情報で、今どうなっているか確認して。確認できた事実と推測を分けて

形にするとき

  • では、この内容でメールを書いて
  • 企画書の構成にして
  • これを読んだ人が、最初に疑問に思いそうなことは？
  • 半分の長さにするなら、絶対に残すものは何？

次回のために

  • 今日決まったことと、次に考えることを短くまとめて
  • 次に相談するとき、最初に貼る文章を作って

使い方のコツ

  • 一度に一つだけ返す。まとめて言うと、返事もぼやける。
  • 「違う」と言うのに理由はいらない。理由は、往復しているうちに見つかる。
  • 3回返して進まなければ、3行に戻る。「理想」か「現状」のどちらかが薄いことが多い。

4迷ったときの早見表

止まったときに、戻る場所があります。

「どうする？」が出てこない。調べ方がわからない。考えが同じところを回る。
そのときに戻る場所です。覚えなくていい。

「どうする？」が思いつかないとき　内・外 → 前 → 実行

今、どこにある情報を使って考えているか。

場所何をする頼み方
内今あるものを整理する（過去の資料、会議の内容、自分の考え、社内のデータ）「今ある情報を整理して」
外足りないものを集める（競合、一般的なやり方、最新情報、専門家の考え）「調べてきて」
前並べて考える（比較する、弱点を出す、優先順位をつける）「提案して」「比較して」「一緒に考えて」
実行決まったものを形にする「作って」「文章にして」「計画にして」
  • 順番どおりに全部やらなくていい。内→前→実行だけで終わることも多い。
  • 迷ったら、まず「内」。すでに持っている材料を出すと、調べなくてよかったとわかることがある。
  • 自分の中だけで回っているなら「外」へ。

「調べてきて」の使い分け　普通・最善・事実

何を知りたくて調べるのかで、頼み方が変わる。

知りたいこと呼び方頼み方
普通はどうしている？デファクトスタンダード「一般的にはどう〜することが多い？」
より良いやり方は？ベストプラクティス「〜のベストプラクティスを調べて。今回の条件に合うものと、やりすぎになりそうなものを分けて」
今、事実としてどうなっている？公式・最新・正確「公式の最新情報を優先して確認して。確認できた事実と、推測を分けて」
  • 「普通」と「最善」と「事実」は違う。
  • 「何について」だけでなく「何を知るために」まで伝える。
    例：「競合の料金を調べて」→「自社の新サービスの価格を決めたいので、同じ顧客層の競合の料金体系を調べて」
  • 出典がなければ「最新」ではないかもしれない。公式情報は自分でも開いて確かめる。

考えが同じところを回るとき　視点・視野・視座

答えを変えるためではなく、見えていなかったものを見るために。

変えるもの問い質問例
視点誰の立場から見るか（横）「顧客から見てどう？」「営業担当者から見たら売りやすい？」「初めて聞く人がわかりにくいところは？」
視野どこまで広く見るか「半年後まで含めると？」「会社全体から見ると？」／広げすぎたら「今回は1か月以内に改善できる範囲に絞って」
視座どの高さから見るか（上下）「部長なら何を気にする？」「経営者から見ると何が足りない？」「逆に、毎日使う担当者の高さに移って考えて」
  • 視座は上げるものというより、動かすもの。上からの見方がいつも正しいわけではない。
  • 一人では出ない反対意見がほしいときは、「この案に反対する人なら、何を問題にする？」
  • 立場の違う人たちに議論してもらいたいときは、「仮想会議プロンプト」へ。

迷ったら、3行に戻る。理想。現状。どうする？

5仮想会議プロンプト

一人では見落とすことを、拾えます。

一人で考えていると、どうしても一人分の見方になる。違う立場の人たちに、AIの中で議論してもらうための型です。
多数決をしてもらうためのものではありません。一人では出てこない懸念や選択肢を出すためのものです。

いちばん短い頼み方

テーマを書いて、その下にこれを貼る。

このテーマについて仮想会議をして。
立場が被らない6人くらいを設定して、それぞれの立場から意見・懸念・反対意見を出して。
最後に、判断するための論点と選択肢を整理して。

これだけで動きます。

3行を先に渡す頼み方（おすすめ）

理想と現状を先に渡すと、議論がずれません。参加者もAIに選んでもらえます。

理想：
現状：
今回考えたいこと：

このテーマについて仮想会議をして。
1. 今回のテーマを考えるのに適切な参加者を、立場が被らないように6人選んで。
2. それぞれの立場から、「ここがいい」「ここが不安」「この情報が足りない」「自分の立場ならこうする」を出して。
3. 意見が分かれたところは、互いに反論させて。
4. 最後に、私が判断するための論点と、選択肢を整理して。結論は出さなくていい。

参加者の選び方

人数より、立場が重ならないことが大事です。マーケターを10人置いても、似た意見になります。

見る角度参加者の例
売る人営業担当
買う人顧客（初めての人／長い付き合いの人）
使う人現場担当者
お金を見る人財務・経理
リスクを見る人慎重派、法務、品質担当
長期で見る人経営者、推進派

迷ったら、AIに「今回のテーマに合う参加者を選んで」と任せて構いません。

会議のあとに返す一言

  • 反対意見のうち、本当に致命的なものはどれ？
  • 顧客役の意見を、もう少し具体的な場面で言い直して
  • この論点で、僕（私）がまだ持っていない情報は何？
  • 今の議論を踏まえて、まず1か月で試すならどの案？

注意

  • 顧客役の発言は、本当の顧客の声ではありません。「こういう不安が出るかもしれない」の候補として使い、本当に大事な点は実際の相手に確かめる。
  • 6人中4人が賛成したからやる、という使い方はしない。決めるのは自分。
  • 社外に出せない情報が混ざっていないか、貼る前に見る。

使いどころの例

  • 新しいサービスや企画を、出す前に一度たたいてもらう
  • 上司や顧客に提案する前に、反対されそうな点を先に出す
  • 二つの案で迷っていて、どちらにも理由があるとき
  • 会議の前に、出そうな論点を先に並べておく

6なべ式プロンプトのテンプレート

対話で固めたことを、形にできます。

これは何をする型か

3行で始めて、対話で考えが固まったあと。文章や資料、システムなど、繰り返し作るものをAIに作らせるときに使う型です。

3行で始める。

対話しながら考える。

必要なら、最後は形にする。

この最後の「形にする」が、なべ式プロンプトです。3行が「考え始めるための型」なら、こちらは「作らせるための型」。

対話をしないまま、この型をいきなり埋めようとすると、空欄が埋まりません。埋まらないのは型のせいではなく、まだ考えが固まっていないからです。そのときは3行に戻ってください。

型（6つの項目）

# 役割
AIに誰として動いてほしいか。どんな立場・経験の人か。

# 目的
何のために作るのか。これが達成できれば成功、という状態。

# スキルセット
その役割に必要な知識や技能。対話で「ここは押さえてほしい」とわかったもの。

# 制約条件
守ってほしいこと。入れないもの。避ける表現。触れてはいけない情報。

# 実行手順
どの順番で進めるか。確認してから書くのか、案を出してから絞るのか。

# 出力フォーマット
何をどんな形で出すか。見出し構成、文字数、ファイル形式、案の数。

前半の3つ（役割・目的・スキルセット）は、誰にお願いするか。
後半の3つ（制約条件・実行手順・出力フォーマット）は、どういう仕事をしてもらうか。

人に仕事を頼むときと同じです。誰に頼むかを決めずに仕事の中身だけ渡しても、仕事の中身を決めずに人だけ選んでも、うまくいきません。だから、6つそろえて渡すのがおすすめです。

対話から型へ移す、いちばん簡単な方法

自分で埋めなくていい。対話がひと区切りついたら、こう頼む。

今のやり取りを、次回そのまま使える指示にまとめて。
役割・目的・スキルセット・制約条件・実行手順・出力フォーマットの項目で整理して。
まだ決まっていない項目は「未定」と書いて。

AIが下書きを作ります。「未定」のところだけ自分で決めれば、型が埋まります。その日の考え方が、自分の型として残ります。

できあがった指示は、一度そのまま使ってみてください。「いや、こうじゃない」と思ったところを直せば、次からは一発で出る指示になります。

例：提案書の前半を作らせる（第11章の続き）

対話で「価格ではなく、自分たちに頼む価値を理解したうえで検討してほしい」と固まったあと。

# 役割
法人向けの提案書を数多く書いてきた営業企画の担当者。

# 目的
価格比較の前に、こちらに頼む価値を相手が理解している状態を作る。

# スキルセット
相手の課題を相手の言葉で言い直す力。
忙しい決裁者が最初の1ページで判断することを踏まえた構成力。

# 制約条件
価格はこの段階では書かない。実績の羅列はしない。専門用語は使わない。
自社の紹介は後ろに回す。

# 実行手順
1. 相手の課題を整理して、こちらの理解を確認する
2. 確認が取れたら、提案書の前半を書く
3. 案を2パターン出し、違いを一言で添える

# 出力フォーマット
A4で1ページ。見出し4つ（相手の課題／解決できる範囲／解決したあとの状態／進め方）。各見出し3〜5行。

型が生きる場面

  • 毎月出す報告書、毎回書く案内文など、同じ種類のものを繰り返し作るとき
  • チームの誰が頼んでも、同じ品質で出てきてほしいとき
  • 一度固めた考えを、次回ゼロから説明し直したくないとき

一度きりのものは、3行と対話だけで十分です。型に固めるのは、二度目があるものだけでいい。

この先

この型の各項目をどう決めるか、成果物ごとにどう変えるか、出てきたものをどう直していくか。そこは本書の先の話です。

まず話す。その中で考える。必要になったら、あとから固める。
