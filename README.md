# 株式会社くじらAIワークス Webサイト

GitHub Pages向けの静的サイトです。

## 構成

- `index.html` — 本文
- `styles.css` — デザイン
- `script.js` — モバイルメニュー等

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成
2. このフォルダ内のファイルをリポジトリ直下へ配置
3. `Settings` → `Pages`
4. `Build and deployment` の Source を `Deploy from a branch`
5. Branch を `main` / `/(root)` に設定して保存
6. 発行されたURLを確認

## 公開前の確認

- お問い合わせ導線を、実際のメールフォーム・メールアドレス等へ変更
- 独自ドメインを使う場合はGitHub PagesのCustom domainを設定
- OGP画像を用意する場合は `og:image` を追加
- 必要に応じて所在地、法人番号、プライバシーポリシー等を追加

## デザイン方針

- 白〜生成りを基調
- 明朝体を見出しに使用
- AI企業にありがちな青紫グラデーションを避ける
- 3秒 / 30秒 / 3分で情報を拾える階層構造
